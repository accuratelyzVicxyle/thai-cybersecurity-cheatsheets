## Local viewer

The included viewer renders Markdown, tables, embedded screenshots, and Mermaid
flowcharts without relying on a Mermaid CDN.

```bash
python3 -m pip install -r requirements.txt
python3 serve_thai.py
```

Then open <http://localhost:9596>.

> Use the security-testing material only in systems and labs where you have
> explicit authorization.
